## 🛡️ What is €SBLCT?

€SBLCT is a **digital representation** of a Standby Letter of Credit — a bank instrument used as payment guarantee in international trade.

**How it works:**

1. Applicant (airline/lessee) requests SBLC from issuing bank
2. Issuing bank issues SBLC with ISP98 conditions
3. AviaTrust records terms on-chain as €SBLCT token
4. Beneficiary (lessor/supplier) receives on-chain proof of guarantee
5. On default — smart contract triggers claim. On maturity — token burns.

**⚠️ Important:** €SBLCT is NOT a bank-issued guarantee. It is a tokenized representation. Legal obligation remains with the issuing bank.
